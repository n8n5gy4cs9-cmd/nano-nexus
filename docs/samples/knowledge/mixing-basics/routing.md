# Mixing basics

## Routing

Routing decides where each track's audio goes before it reaches the master output.

### Sends
A send copies part of a track's signal to a bus so several tracks can share one effect, such as a reverb. To set one up, open the track's routing button, add a send, pick the destination bus, and raise the send level. A pre-fader send ignores the track fader; a post-fader send follows it.

### Buses and groups
A bus sums several tracks into one channel so you can process them together, for example all drums through one compressor.

### Sidechain
Sidechain compression lowers one track whenever another plays. Route the kick to the compressor's sidechain input on the bass track, then set threshold and ratio until the bass ducks with each kick.
